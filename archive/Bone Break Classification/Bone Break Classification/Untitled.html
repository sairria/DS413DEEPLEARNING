LABORATORY 201#

🎯 Objective In this lab, you will explore how different activation functions and optimizers affect the performance of a deep learning model. You will apply these hyperparameters to a custom image dataset of your choice and analyze how each configuration influences model training and accuracy.

📂 Instructions Dataset Selection

Look for a custom image dataset online. You may use sources such as:

Kaggle Datasets Roboflow Universe Google’s Dataset Search Choose a dataset with 2–10 classes (e.g., fruits, animals, flowers, or objects).

Make sure the dataset has enough samples per class for training and validation (at least a few hundred images in total).

Model Setup

Build a simple Convolutional Neural Network (CNN) for image classification.

Keep your architecture fixed across all experiments (only change the activation and optimizer).

Suggested layers:

2–3 convolutional layers ReLU, LeakyReLU, ELU, Sigmoid, or Tanh as possible activation functions Adam, SGD, RMSprop, or Adagrad as possible optimizers Output layer using Softmax or LogSoftmax for classification Experiment Design

Prepare at least 4–6 experiment combinations by changing only:

The activation function, and The optimizer Keep all other parameters constant (epochs, batch size, learning rate, etc.).

Example setup:

Experiment Activation Function Optimizer Remarks 1 ReLU SGD Baseline 2 ReLU Adam Test optimizer effect 3 LeakyReLU SGD Test activation effect 4 LeakyReLU Adam Combined change 5 ELU RMSprop Extra comparison Training and Testing

Train the model for a fixed number of epochs (e.g., 10–20).

Record the following for each experiment:

Training and validation loss curves Training and validation accuracy curves Final test accuracy or F1-score Plot the results using Matplotlib or any visualization library.

Analysis and Explanation

Compare the results of each experiment.

Explain why you think certain combinations performed better or worse.

Discuss:

How activation functions influence learning (e.g., vanishing gradient, dead neurons, non-linearity). How optimizers affect convergence speed and stability. Which combination achieved the best trade-off between accuracy and generalization. Deliverables Submit the following items:

A. Jupyter Notebook (.ipynb)

Includes your code, output plots, and experiment logs. Organized and properly labeled for each experiment. B. Short Report

Dataset overview (name, size, number of classes) Experiment setup table (activation + optimizer combinations) Key results (loss and accuracy curves) Explanations and insights for each configuration Final summary: Which combination performed best and why.
